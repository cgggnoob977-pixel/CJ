# คลังข้อมูล — Logistics dashboard

แดชบอร์ดภาษาไทยสำหรับสำรวจข้อมูลพัสดุจาก `delivery_logistics_dirty_200.csv` โดยใช้ Sidebar เปลี่ยนหน้าระหว่างภาพรวม รายการพัสดุ วิเคราะห์ขนส่ง และคุณภาพข้อมูล ตัวกรองทุกตัวทำงานร่วมกันและอัปเดตทุกหน้า

> **ขอบเขตข้อมูล:** PDF ที่แนบมากำหนดโจทย์ร้านเครื่องดื่ม แต่ CSV ที่ให้มาคือข้อมูลขนส่ง แดชบอร์ดนี้จึงยึด CSV ขนส่งตามที่เลือก ไม่ได้คำนวณยอดขายเครื่องดื่มหรือกำไรขั้นต้น

## วิธีเปิด

1. ติดตั้ง Python 3 (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์
3. สร้างข้อมูลที่จัดรูปแบบแล้ว: `python scripts/clean_data.py`
4. เปิดเว็บเซิร์ฟเวอร์ในโฟลเดอร์โปรเจกต์: `python -m http.server 8000`
5. เข้า `http://localhost:8000`

สคริปต์อ่านไฟล์ดิบใน `data/` และสร้าง `data/shipments_clean.csv`, `data/shipments.js` และ `data/quality_summary.json` ใหม่ทุกครั้ง

## หน้าหลัก

- **ภาพรวม:** KPI จำนวนพัสดุ อัตราส่งสำเร็จ ระยะเวลาจัดส่งเฉลี่ย ค่าจัดส่งรวม แนวโน้มรายเดือน สถานะ และบริษัทขนส่ง
- **รายการพัสดุ:** ค้นหา กรอง เรียงลำดับ แบ่งหน้า และส่งออก CSV ตามตัวกรอง/คำค้น
- **วิเคราะห์ขนส่ง:** เปรียบเทียบบริษัทขนส่ง ภูมิภาค และช่องทางสั่งซื้อ
- **คุณภาพข้อมูล:** สรุปการทำความสะอาด ค่าที่ผิดปกติ ข้อค้นพบ ข้อเสนอแนะ และข้อจำกัด

ตัวกรองวันที่อิง **วันที่รับพัสดุ** และใช้เฉพาะแถวที่มีวันที่ถูกต้อง เมื่อค้นหาไม่พบข้อมูลจะแสดงคำแนะนำให้ล้างตัวกรอง

## วิธีทำความสะอาด

1. ตัดช่องว่างหัวท้ายก่อนตรวจแถวซ้ำ
2. ลบเฉพาะแถวที่ซ้ำกันทุกคอลัมน์หลังตัดช่องว่าง โดยเก็บแถวแรกไว้
3. รวมชื่อบริษัท ภูมิภาค วิธีชำระเงิน สถานะ และช่องทางที่เป็น alias ให้ใช้ชื่อเดียวกัน
4. แปลงวันที่เป็น ISO (`YYYY-MM-DD`); วันที่ที่อ่านไม่ได้เก็บเป็นค่าว่าง
5. แปลงตัวเลขที่มี comma/สัญลักษณ์บาท และเก็บค่าที่แปลงไม่ได้เป็นค่าว่าง ไม่แทนด้วยศูนย์
6. ค่าติดลบในน้ำหนัก ระยะทาง ค่าจัดส่ง ค่าบริการ COD มูลค่าสินค้า และระยะเวลาจัดส่ง รวมถึงคะแนนนอกช่วง 1–5 และจำนวนครั้งจัดส่งต่ำกว่า 1 ถูกทำเป็นค่าว่าง
7. tracking ID ที่ซ้ำแต่รายละเอียดต่างกัน **คงไว้ทั้งสองรายการ** และทำเครื่องหมาย collision; ไม่สรุปว่าเป็นแถวซ้ำ
8. ค่าที่เกินเกณฑ์ตรวจทานแสดงเป็น outlier แต่ยังคงอยู่ในผลรวมและกราฟ เพื่อไม่ลบข้อมูลจริงโดยไม่มีหลักฐาน เกณฑ์เป็น heuristic ไม่ใช่หลักฐานว่าค่านั้นผิด

**การตีความตัวเลข:** จำนวนพัสดุนับแถวที่ไม่ซ้ำทั้งแถว; อัตราส่งสำเร็จนับสถานะหลังรวม alias; ระยะเวลาจัดส่งเฉลี่ยใช้ค่าที่ไม่ติดลบและยังมีข้อมูล; ค่าจัดส่งรวมบวกค่าที่อ่านได้หลังตัดค่าติดลบ แต่ยังรวม outlier ที่ต้องตรวจสอบด้วย

## ตรวจความถูกต้องและความเร็ว

- ทำซ้ำขั้นตอนเตรียมข้อมูลด้วย `python scripts/clean_data.py` แล้วตรวจจำนวนแถวใน `data/quality_summary.json`
- ทดลองกรองช่วงวันที่ สถานะ และบริษัทพร้อมกัน ตรวจ KPI/กราฟ/ตาราง แล้วกด **ล้างตัวกรอง**
- ค้นหารหัสที่ไม่มีอยู่เพื่อทดสอบ empty state
- ส่งออก CSV แล้วเทียบกับผลการค้นหา/ตัวกรองบนหน้า **รายการพัสดุ**
- เวลา render/กรองแสดงในส่วนท้ายของหน้า วัดด้วย `performance.now()` เฉพาะเวลาคำนวณและวาดหน้าในเบราว์เซอร์ ไม่รวมเวลาเปิดเซิร์ฟเวอร์หรือดาวน์โหลดไฟล์

## ข้อจำกัด

- CSV เป็นชุดข้อมูลฝึกที่มีค่าว่าง ค่าผิดรูปแบบ และ outlier; ค่าที่ระบบตั้งธงต้องยืนยันกับแหล่งข้อมูลต้นทางก่อนใช้ตัดสินใจจริง
- tracking ID ที่ซ้ำและมีรายละเอียดต่างกันยังแยกเป็นคนละแถว เพราะไม่มีข้อมูลยืนยันว่าแถวใดถูกต้อง
- เปอร์เซ็นต์และค่าเฉลี่ยขึ้นกับสถานะ/ค่าที่ระบุได้; ไม่อนุมานเหตุผลหรือแก้ข้อมูลทางธุรกิจที่ไม่ชัดเจน
- เว็บไซต์ใช้ข้อมูลฝังในไฟล์ JavaScript ที่สร้างจาก CSV สำหรับรันแบบ local; สร้างไฟล์ดังกล่าวใหม่หลังเปลี่ยนข้อมูลดิบ
